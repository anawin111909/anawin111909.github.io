LifeRun

Game developed by Draghici Andrei — tested independently as a QA practice project.

LifeRun is a top-down fantasy survival RPG featuring five playable classes and wave-based combat. Tested as part of a personal Game QA practice project on Android build version 1.0 Alpha. The testing process focused on gameplay mechanics, character creation, UI functionality, audio behavior, save/load system, and overall game stability across a 20-wave survival run structure.
